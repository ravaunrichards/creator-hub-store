# Roadmap

1. Complete admin review UI and role-protected approval/rejection endpoints.
2. Integrate isolated malware scanning, package signing-certificate inspection, and upload quarantine.
3. Move APK delivery to private object storage/CDN with checksums and resumable downloads.
4. Add app screenshots/icons, changelogs, ratings/reviews with abuse controls, update feeds, and developer analytics.
5. Build native Android companion client with safe package install handoff and update checks, subject to Android restrictions.
6. Add verified developer accounts, email verification, password recovery, user reports, and a formal takedown workflow.
